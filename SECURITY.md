# Security policy

## Supported versions

Security fixes are applied to the current `main` branch. This project does not
yet publish supported release branches.

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub's private vulnerability reporting](https://github.com/Swamy-BV/kicad-flow/security/advisories/new).
Include the affected version or commit, a way to reproduce the issue, and its
impact. Do not include exploit details in a public issue.

If private reporting is unavailable, open a public issue **without sensitive
details** to request a private contact channel. We will acknowledge the report
and coordinate a fix and disclosure with you.
